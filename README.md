🎉 Event Registration System

📌 Overview

This is a simple web-based event registration system built using HTML, CSS, and JavaScript. It allows users to register for events and manages seat availability dynamically.


🚀 Features

- User registration form
- Form validation
- Dynamic seat count
- Display registered users
- Local storage support
- Responsive design


🛠️ Technologies

- HTML
- CSS
- JavaScript


⚙️ How It Works

Users fill the form → Data is validated → Stored in localStorage → Seats update → Participants list displayed.
